## Installation and Setup

To clone this repository and set up te course environment on your local machine, use the inline command `git clone` as shown below.

You can initialize and manage the environment using **Pixi** (or standard Conda commands if preferred). Here is how to download the repository and activate your environment:

```bash
# Clone the repository
git clone https://github.com

# Navigate into the project folder
cd MLGEO2026_MLSTRAP

# Install packages and activate the environment
pixi install
```

## Running the Notebooks
Once your environment is activated and the package is installed, you can spin up your interactive workbook environment using the following runtime command:
```bash
pixi run lab
```
